# velolog-signature-studio

Official VELOLOG Corporate Website and Email Signature Generator Studio.

## Features
- Complete multi-page corporate website for VELOLOG (Home, About Us, Team, Services, Contact)
- Interactive Email Signature Studio for all 9 logistics staff members
- Exact corporate branding with verified ISO 9001 and JCTRANS seals
- Email-safe HTML signatures with embedded Base64 assets
- High-resolution PNG and HTML downloads
- Local Node.js preview server with dynamic staff and photo management

## Getting Started
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3000/signature-studio](http://localhost:3000/signature-studio) in your browser.
